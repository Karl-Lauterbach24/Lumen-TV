# media3-decoder-ffmpeg-1.5.1.aar

Media3's FFmpeg audio decoder (`libraries/decoder_ffmpeg` of androidx/media 1.5.1, Apache 2.0) with
FFmpeg 6.0 (`release/6.0`, LGPL 2.1+, built without GPL parts) for armeabi-v7a, arm64-v8a, x86 and
x86_64. Decoders: `ac3 eac3 dca truehd mlp` – Dolby Digital (Plus), DTS (with DTS-HD) and Dolby TrueHD,
which most televisions cannot decode themselves.

Built with `tools/build_ffmpeg_decoder.sh`.
