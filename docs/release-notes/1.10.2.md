# Lumen TV 1.10.2

## What is new

- MakeMKV's Linux tree now has the television's CA certificates (`/etc/ssl/certs/ca-certificates.crt`, `SSL_CERT_FILE`) and a
  `/etc/hosts`, so that anything MakeMKV asks its servers over TLS can be verified.
- Diagnostics: a file `shimlog` in the app's folder makes the drive shim log every SCSI command in full (command bytes and the
  start of the answer), to compare what MakeMKV asks a drive for. Used to look at 4K discs (AACS 2), for which MakeMKV on the
  television still says "the volume key is unknown": the drive's answers look like those of a normal Blu-ray, the reads succeed.
