# Lumen TV 1.9.2

## What is new

- **A disc whose key MakeMKV does not know says so.** A new 4K disc (AACS 2) can be newer than MakeMKV's list:
  MakeMKV opens the drive, then reports "the volume key is unknown for this disc". The disc page used to show
  only the button to read the disc again; it now names the reason (and keeps the button to try again).
  There is nothing the app can do about it: MakeMKV has sent the disc for analysis, and a newer MakeMKV version
  (2.0.0 is the latest at the time of writing) is what solves it.
