# Lumen TV 1.12.1

## Changed

- **4K discs through the key database are experimental and only on request.** On the drive tested, reading a 4K disc the app's own
  way has hung the drive (and its USB bridge) several times – also with LibreDrive on, also when only the disc's directories were
  read – and only switching the drive off brought it back. A 4K disc is now MakeMKV's unless *Try with the key database (experimental)*
  is chosen on its page.

## Fixed

- **Another disc in the drive is noticed**: the drive's "new medium" note can be taken by another command first; a disc of another
  size now counts as another disc too.
- A drive whose disc is not read yet no longer shows an earlier disc's picture.
