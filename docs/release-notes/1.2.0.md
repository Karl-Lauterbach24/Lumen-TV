# Lumen TV 1.2.0

## What is new

- **A new interface**, the one of LumenOS: cards, a selection that glides, pages that slide, an opening
  picture, a screen saver, short sounds and a quiet loop in the menus (switchable in *Settings*). In all
  16 languages. All three apps (Android TV, Samsung, LG) and the page Lumen serves to browsers show it.
- **Films from a drive connected to the television.** *USB drive* lists the volumes the television
  mounted and the folders and films on them, and plays them itself – no computer needed. On Android TV
  the player is Media3: Dolby and DTS go to the receiver as they are where the television allows it, HDR
  and the film's frame rate are the system's.
- Still there: *From Lumen* – the stream Lumen casts, with the television's remote operating Lumen.
- The Android app's source code is in the repository again: a rule in `.gitignore` (`lumen/`) had
  excluded the app's package folder (`io/github/lumen/tv`), so the Kotlin files were never committed and
  the APK of 1.1.0 was built without them. The app is now a WebView with this page and a native player.

## Checked, and limits

Run in the Android TV emulator (Android 14, ARM64, Apple Silicon): the interface and its keys, the
volumes and folders of the emulated storage, playing from them with seek, pause and the media keys,
Back, and a cast from a stand-in Lumen (found on the network, played as HLS, state reported).
**Not tried on a real television**, so not tried: a USB drive on a real television (the system's media
index decides what shows – films it has not indexed do not), Dolby/DTS passthrough, HDR, the Samsung and
LG apps with the new page. A disc drive connected to the television shows only what the system itself
mounts of it.
