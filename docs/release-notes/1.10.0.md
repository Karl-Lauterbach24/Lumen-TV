# Lumen TV 1.10.0

## What is new

- **Updates are looked for by themselves.** Once a day (and under *Settings › Updates › Check for updates now*) the app asks
  GitHub for the newest Lumen TV and MakeMKV's forum for the newest MakeMKV, and says when one is out
  (a message on the screen, once per version; the page under *Settings › Updates* shows both).
- **A disc whose key MakeMKV does not know** says it with the reason, and what the newest MakeMKV is: "MakeMKV 2.1.0 is
  out – it should work with that", or "there is no newer MakeMKV yet; the disc has been sent for analysis".
- A failed check says where it failed (GitHub, the MakeMKV forum) instead of staying silent.

## Not done by the app

- It does not install what it finds. MakeMKV's files are part of the app (they cannot be exchanged while it runs and are not
  ours to hand out), and an update of the app is signed with its builder's key – a package signed by someone else cannot
  replace it. The page says so.
